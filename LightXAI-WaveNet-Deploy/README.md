# 🫁 LightXAI-WaveNet — GUI Dashboard

**A Hybrid DWT-SVD-CNN-Vision Transformer Framework for Early Detection of Sub-5 mm Pulmonary Nodules from Low-Dose CT Scans**

## 📋 Deskripsi

Repository ini berisi **GUI Dashboard** (Streamlit) untuk framework **LightXAI-WaveNet** — model klasifikasi 5 kelas (C0–C4) untuk deteksi dini nodul paru-paru dari CT scan dosis rendah.

Dashboard ini menampilkan:
- 🩻 DICOM Viewer dengan reticle otomatis di area nodul
- 🔮 Prediksi kelas + confidence + softmax probabilities
- 🩺 Clinical decision (risk level, diameter, rekomendasi)
- 📊 ROI information + 3D visualization (interaktif, bisa diputar)
- 🧠 CNN local features & Vision Transformer attention
- 💡 Grad-CAM explainability
- 📈 Confusion matrix, ROC curve, ablation study
